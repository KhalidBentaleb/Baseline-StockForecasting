## 📌 Overview  

This repository provides a benchmarking framework for baseline forecasting models on financial time series.

The framework includes:

- Machine learning models for stock prediction  
- Deep learning architectures for temporal modeling  

Experiments are conducted on daily stock data (OHLCV features) for:

- Next-day price prediction  
- Market direction classification  

Models are evaluated and compared under consistent experimental settings to establish a robust empirical baseline.
